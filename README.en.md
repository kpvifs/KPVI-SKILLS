# Persuasion Coach / Expression Coach

[简体中文](README.md) | English | [日本語](README.ja.md)

Frameworks for two Claude Code Skills, designed from the 35 lessons of Huang Chih-Chung's (黄执中) course "35-Day Persuasion Bootcamp" (说服力三十五日训练营).

| Directory | Skill | Scope |
|---|---|---|
| `shuofu-jiaolian/` | Persuasion Coach (说服教练) | What to say: whether persuasion is the right tool, whether the audience is opposed, neutral or supportive, which point to move them to, and which method to use. |
| `biaoda-jiaolian/` | Expression Coach (表达教练) | How to say it: structure, transitions, examples, rhetorical questions, recaps. |

Both Skills support four modes: reviewing a draft or script, proposing an approach for a scenario, role-play practice, and explaining a concept or technique.

## What this repository contains

- Only the two `SKILL.md` files: role, decision flow, modes and output rules.
- It does not contain the `references/` knowledge base (lesson notes, course map and summary files). The `references/` files mentioned in `SKILL.md` are not in this repository.
- Without the knowledge base, these Skills cannot answer from the course content.
- `SKILL.md` and the course material are written in Simplified Chinese.

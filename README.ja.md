# 説得コーチ / 表現コーチ

[简体中文](README.md) | [English](README.en.md) | 日本語

黄執中（Huang Chih-Chung）の講座「説得力35日間トレーニングキャンプ」（原題：说服力三十五日训练营）全35回をもとに設計した、Claude Code Skill 2つのフレームワークです。

| ディレクトリ | Skill | 担当範囲 |
|---|---|---|
| `shuofu-jiaolian/` | 説得コーチ（说服教练） | 何を言うか：説得で解決すべきか、聞き手が反対・中立・支持のどれか、どこまで動かすか、どの手法を使うか。 |
| `biaoda-jiaolian/` | 表現コーチ（表达教练） | どう話すか：構成、話のつなぎ、例の挙げ方、問いかけ、振り返り。 |

どちらの Skill にも4つの使い方があります：原稿やトークの診断、場面に応じたプランの提案、ロールプレイ練習、概念や手法の解説。

## このリポジトリの内容

- 2つの `SKILL.md`（役割、判断フロー、使い方、出力ルール）のみを含みます。
- `references/` ナレッジベース（講義ノート、講座マップ、まとめファイル）は含みません。`SKILL.md` で言及している `references/` のファイルは、このリポジトリにはありません。
- ナレッジベースがない状態では、講座の内容に基づいて回答することはできません。
- `SKILL.md` と講座資料は簡体字中国語で書かれています。

# KPVI-SKILLS

[简体中文](README.md) | [English](README.en.md) | 日本語

Claude Code Skill 3つのフレームワークです。

| ディレクトリ | Skill | 担当範囲 | もとにした講座 |
|---|---|---|---|
| `shuofu-jiaolian/` | 説得コーチ（说服教练） | 何を言うか：説得で解決すべきか、聞き手が反対・中立・支持のどれか、どこまで動かすか、どの手法を使うか。 | 黄執中（Huang Chih-Chung）の講座「説得力35日間トレーニングキャンプ」（原題：说服力三十五日训练营）全35回 |
| `biaoda-jiaolian/` | 表現コーチ（表达教练） | どう話すか：構成、話のつなぎ、例の挙げ方、問いかけ、振り返り。 | 同上 |
| `yunying-guwen/` | 運営アドバイザー（运营顾问） | ショップ、アカウント、商品、サービスの運営：トラフィックとアルゴリズム、集客導線、コンバージョン、客単価、商品選定とビジネスモデル、個人IP、コンテンツ、プライベートトラフィック、コミュニティ。 | 講座「7分课·运营」全18回 |

説得コーチと表現コーチには4つの使い方があります：原稿やトークの診断、場面に応じたプランの提案、ロールプレイ練習、概念や手法の解説。

運営アドバイザーには4つの使い方があります：運営上の問題の診断、プランの提案、概念の解説、既存プランのレビュー。

## このリポジトリの内容

- 3つの `SKILL.md`（役割、判断フロー、使い方、出力ルール）のみを含みます。
- `references/` ナレッジベース（講義ノート、講座マップ、まとめファイル）は含みません。`SKILL.md` で言及している `references/` のファイルは、このリポジトリにはありません。
- ナレッジベースがない状態では、講座の内容に基づいて回答することはできません。
- `SKILL.md` と講座資料は簡体字中国語で書かれています。

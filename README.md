# 说服教练 / 表达教练

两个 Claude Code Skill 的框架，基于黄执中「说服力三十五日训练营」35 节课设计。

| 目录 | Skill | 管什么 |
|---|---|---|
| `shuofu-jiaolian/` | 说服教练 | 说什么：判断该不该说服、听众是反对/中立/支持哪一类、目标定在哪一点、用哪个方法。 |
| `biaoda-jiaolian/` | 表达教练 | 怎么讲：结构、转场、举例、设问、复习等讲法。 |

两个 Skill 都有四种用法：诊断稿子或话术、按场景出方案、陪练对练、讲解概念或手法。

## 本仓库包含什么

- 只含两份 `SKILL.md`：角色、判断流程、用法和输出规则。
- 不含 `references/` 知识库，即课程笔记、课程地图和汇总文件。`SKILL.md` 里提到的 `references/` 文件都不在本仓库里。
- 没有知识库时，这两个 Skill 不能按课程内容回答。

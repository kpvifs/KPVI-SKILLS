# KPVI-SKILLS

简体中文 | [English](README.en.md) | [日本語](README.ja.md)

三个 Claude Code Skill 的框架。

| 目录 | Skill | 管什么 | 依据的课程 |
|---|---|---|---|
| `shuofu-jiaolian/` | 说服教练 | 说什么：判断该不该说服、听众是反对/中立/支持哪一类、目标定在哪一点、用哪个方法。 | 黄执中「说服力三十五日训练营」35 节课 |
| `biaoda-jiaolian/` | 表达教练 | 怎么讲：结构、转场、举例、设问、复习等讲法。 | 同上 |
| `yunying-guwen/` | 运营顾问 | 店铺、账号、产品、服务的运营：流量与算法、引流布局、转化、客单价、选品与产品模式、IP、内容、私域、社群。 | 「7分课·运营」18 课 |

说服教练和表达教练有四种用法：诊断稿子或话术、按场景出方案、陪练对练、讲解概念或手法。

运营顾问有四种用法：运营诊断、出方案、解释概念、评审已有方案。

## 本仓库包含什么

- 只含三份 `SKILL.md`：角色、判断流程、用法和输出规则。
- 不含 `references/` 知识库，即课程笔记、课程地图和汇总文件。`SKILL.md` 里提到的 `references/` 文件都不在本仓库里。
- 没有知识库时，这三个 Skill 不能按课程内容回答。
